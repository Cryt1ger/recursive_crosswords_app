# Рекурсивные кроссворды

Статичный Telegram Mini App с одним рекурсивным кроссвордом в духе
[Bracket City](https://www.theatlantic.com/games/bracket-city/).

Решаются только внутренние загадки: правильный ответ подставляется в текст
родительской подсказки и делает её доступной.

## Локальный запуск

Из корня проекта:

```bash
python -m http.server 8080
```

Откройте `http://localhost:8080`. Можно также просто открыть `index.html`
в браузере — скрипты обычные (не модули), поэтому `file://` тоже работает.

## Как редактировать загадку

Редактируйте только [`puzzle.md`](puzzle.md). Файл [`content.js`](content.js)
генерируется из него и перезаписывается при сборке — его не нужно трогать
вручную.

```bash
node build.js           # один раз
node build.js --watch   # автоматически при каждом сохранении puzzle.md
```

Зависимости не нужны: используется только Node.js. Если в загадке нет ответа
или ответ указан для несуществующей загадки, сборка остановится с сообщением
о пути (`0`, `0.0`, `1`, …).

### Формат `puzzle.md`

Секция `## Текст` — сам текст загадки. Ответ пишется прямо внутри загадки
после `=>` (можно `→`), варианты разделяются `/`:

```md
## Текст

На [мебель, где сидит [мяукающее животное => кот/кошка] => диван]е лежит книга.
```

Здесь `0.0 = кот`, `0 = диван`. Порядок и вложенность загадок определяют пути
автоматически — номера писать не нужно. Ответом может быть часть слова,
поэтому в примере получается `На диване лежит книга.`

Дополнительные подсказки задаются после `;` в той же загадке:

```md
[мяукающее животное => кот/кошка ; буква: к ; слово: кот]
```

- `буква` (или `first`) — что показать в подсказке №1;
- `слово` (или `full`) — что показать в подсказке №2 и подставить в текст.
  Если не задано, берётся первый вариант из ответов.

Это же поле удобно, когда нужно принять несколько вариантов ввода, но
показывать один канонический:

```md
[герой марвел => вижн/вижен ; слово: вижен]
```

Тогда `вижн` и `вижен` оба засчитываются, а в текст подставляется `вижен`.

Литеральные символы `[` и `]` в подсказке экранируются обратной косой
чертой. Например, `множество \[0; 1\]` останется текстом, а не новой загадкой.

### Секции

- `## Финал` — необязательный точный текст финального экрана. Если его нет,
  текст собирается из ответов. Сборка печатает, совпадает ли собранный текст
  с указанным.
- `## Ответы` — необязательный раздел для переопределений по путям:

```md
## Ответы

- `0.0` = кот / кошка ; буква: к ; слово: кот
```

Это удобно, если ответы проще держать списком, а не в тексте. Ответы из этого
раздела перекрывают answers из загадок; лишние пути вызовут ошибку сборки.

### Правила ответов

- Сравнение нечувствительно к регистру, `ё`/`е` и лишним пробелам.
- Внутри загадки сначала решаются вложенные; внешняя открывается только когда
  все внутренние решены.
- Подсказка №1 стоит 10 баллов, №2 — 25 и сразу решает загадку.

## Баллы и время

Старт 100. Неверная попытка −5, подсказка-буква −10, подсказка-слово −25.
В конце показывается итоговое число баллов.

Таймер идёт с момента открытия загадки, останавливается на финальном экране
и не влияет на баллы. Если свернуть приложение, время не считается — при
возврате отсчёт продолжается с того же места. Формат `ММ:СС`, после часа —
`Ч:ММ:СС`.

Правило штрафа показано и в подсказке под текстом, и прямо в форме ответа:
неверная попытка стоит −5 баллов.

## Логи

Под загадкой появляется блок «Что открыл»: для каждой решённой загадки видно
её подсказку и найденное слово. Новые записи добавляются сверху.

## Telegram Mini App

1. Создайте бота через [@BotFather](https://t.me/BotFather).
2. `/newapp` → укажите HTTPS-адрес задеплоенного сайта.
3. `/setmenubutton` → Web App URL ↔ тот же адрес, чтобы приложение
   открывалось из меню бота.

Внутри Telegram используются `MainButton` и `HapticFeedback`; в обычном
браузере отображается обычная кнопка.
